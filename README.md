# Cyber Threat Hunting

A collection of threat-hunting methodology, research notes, and automation projects focused on developing and operationalizing detection hypotheses across enterprise environments.

## Repository Contents

### IoC Script Automation

PowerShell automation for converting Indicators of Compromise (IoCs) from structured source data into Suricata IDS rules.

The project was developed to reduce the manual effort required to operationalize threat-intelligence reporting and support intelligence-driven threat hunts.

**Key areas:**
- Indicator processing and normalization
- Suricata rule generation
- Threat-intelligence-driven detection
- PowerShell automation

See the [`IoC Script Automation`](./IoC%20Script%20Automation) directory for the implementation and supporting documentation.

Notes and methodology for developing structured threat hunts, including defining hypotheses, identifying relevant telemetry, and documenting expected attacker behavior.
